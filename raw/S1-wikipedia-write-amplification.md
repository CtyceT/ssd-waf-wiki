## 原文擷取

1. "Write amplification (WA) is an undesirable phenomenon associated with flash memory and solid-state drives (SSDs)"
2. "WA is typically measured by the ratio of writes committed to the flash memory to the writes coming from the host system."
3. "Because flash memory must be erased before it can be rewritten"
4. "Data is written to the flash memory in units called pages (made up of multiple cells)."
5. "However, the memory can only be erased in larger units called blocks (made up of multiple pages)."
6. "only the pages with good data in that block are read and rewritten into another previously erased empty block."
7. "Then the free pages left by not moving the stale data are available for new data."
8. "the additional space from over-provisioning helps lower the write amplification"
9. "but it gives back reduced write amplification, increased endurance, and increased performance."
10. "The difference between these two values is 7.37% (= (230 − 109) / 109 × 100%)."
11. "This is done typically at 0%, 7%, 14% or 28%"
12. "the OS sends the TRIM command along with the LBAs that no longer contain valid data."
13. "This informs the SSD that the LBAs in use can be erased and reused."
14. "Writing non-sequential data and smaller data sizes will have greater impact on write amplification"
15. "Flash memory can be programmed and erased only a limited number of times."
16. "A lower write amplification is more desirable, as it corresponds to a reduced number of P/E cycles"
17. "Without compression, WA cannot drop below one."
18. "Using compression, SandForce has claimed to achieve a write amplification of 0.5"
